# KSP Macropad — Mod

KSP 1.12.5 C# plugin that bridges the macropad to the game over USB serial. Reads live telemetry from the KSP API and executes macro sequences programmatically on key events received from the pad.

## Status
- [x] Dev environment set up
- [x] NuGet dependencies installed
- [ ] Serial communication
- [ ] Telemetry reading
- [ ] Macro execution
